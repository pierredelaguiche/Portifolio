# Portfolio
 
Personal portfolio site, built as a single self-contained HTML page.
 
**Live:** https://pierredelaguiche.github.io
 
## Stack
 
- Static HTML + React (in-browser, no build step)
- Custom design system (buttons, cards, nav, panels)
- No dependencies to install — it's one file
## Run locally
 
Just open `index.html` in a browser. No server, no build.
 
## Deploy
 
Pushed to `main`, served via GitHub Pages. Any push to this branch updates the live site.
