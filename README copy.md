# Portfolio

Personal portfolio site.

**Live:** https://pierredelaguiche.github.io/Portifolio

## Stack

- Static HTML + React (in-browser, no build step)
- `data.js` — all editable content (experience, projects, languages). Edit this for content changes.
- `components.js` — reusable UI pieces (Button, Tag, NavBar, Card, PixelPanel). Rarely needs touching.
- `app.js` — page sections (Hero, About, CV, Work, Contact) built from the two files above.
- `style.css` — design tokens (colors, type, spacing) and base styles.

## Run locally

Open `index.html` in a browser. No server, no build.

## Deploy

Pushed to `main`, served via GitHub Pages. Any push to this branch updates the live site.
